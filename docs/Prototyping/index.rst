Prototyping Flow
================

Chipyard supports FPGA prototyping for local FPGAs supported by `fpga-shells <https://github.com/sifive/fpga-shells>`__.
Supported targets include the Xilinx VCU118 and ZCU104, and the Digilent Arty A7-35T/A7-100T, Nexys Video, and Genesys 2 boards.
